# Bioupgrade academic catalogue update

8 November 2026. This revision extends the recovered source, not a replacement Shopify store. The original design/wordmark, Stripe architecture, protected account, durable points/orders/referrals and source IDs are preserved.

## What is present

The shop now defaults to all27current owner-list variants, with exact names, stated pack quantities, brand labels and EUR prices. Topic/family/brand search and pagination, credited imagery, detail-page links and the existing explicit-consent saved-interest flow connect the catalogue to the account. The23older attachment-source labels/prices remain in a separate archive. Four legacy concepts remain for saved-reference continuity; they no longer lead the shop. Repeated names/strengths from the image are not silently merged with the owner’s newer prices.

Each current variant has a `/shop/<id>` source/specification page. Across16family briefs,21unique primary papers supply authors, year, journal, DOI/PMID, study type, finding, limitation and relationship to the named entity. The library `/research` supports search and topic/family/study filters plus paper/brief views. `/meta` is a dated substantive editorial on precision molecular development, endpoints and inference. `/community` explains the actual educational scope, points/referrals and available tier benefits, with a local temporary question builder—not a live forum or a request submission. `/documentation` distinguishes literature, price labels and batch COA/SDS standards without forging certificates or legal policies. Homepage, navigation and footer point to these completed destinations.

Undefined Klow/Glow composition and the HGH-fragment sequence remain unresolved. The Wolverine record keeps BPC/TB-500 component research separate from blend evidence and full-length thymosin-beta-4; the abbreviated BPC label is not silently normalised. The CJC no-DAC wording is not substituted for long-acting CJC-1295. Papers about telomerase/cell culture, formulations/routes or narrow clinical populations are not promoted into broad longevity/performance claims. Negative clinical results and correction context remain visible.

Eight PubChem2D structure diagrams have unique CID/exact-name provenance. One25mgZPHCkit packaging reference has a visible third-party/label-only caption. Other variants use a named-entity diagram or an honestly labelled licensed laboratory photograph—not a synthetic or mismatched supplier photo. The actual lot/product pictures are owner inputs. Small static derivatives are packaged in the app; original hero storage still needs the original binding or file.

Public pages contain initial server-rendered text and citations, route-specific escaped metadata and real404responses. Private account data are not server-rendered. Canonicals/sitemap use only an explicitly configured final HTTPS origin; an unconfigured session does not fabricate a public address. Client route navigation updates the same shared metadata. The local community draft is excluded from the existing development replay collector via its supported `manus-no-record` boundary.

## What this does not establish

Owner-listed products are not a verified stock ledger: current lot counts, COAs/SDS, composition/sequence where missing, actual supplier photos, legal seller identity, shipping/refund/fulfilment facts and qualified classification/destination review have not been supplied. Research-material checkout remains disabled. The application does not yet implement approved research-organisation verification or procurement. Points or membership do not establish research eligibility, and research-material purchases/referrals earn no rewards.

The display uses scientific study-type and identity context, not FDA approval ranking. It also does not declare every named material lawful simply because it is labelled research-only. Operating from Estonia, Germany or Portugal still requires the actual seller, classification, intended-use and destination facts. Provider eligibility is separate from scientific publication and from storefront architecture.

`PRODUCTION_CONNECTIONS.md` explains exact secure environment values, the existing managed Stripe live-key pair/republish flow, original runtime storage presigns and the difference between configuration readiness and real connectivity. No live credentials, migration, payment, new webhook, publication or third-party account changes were performed for this extension. The original editable website resource is still required for a permanent managed release.
